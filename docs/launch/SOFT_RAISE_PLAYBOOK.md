# Bridge / Soft Raise — کارنکس (۶ ماه runway)

فقط وقتی **runway شخصی &lt; ۸ هفته** است این سند را فعال اجرا کن. در غیر این صورت رابطه بساز، کلوز نکن.

## روایت یک‌خطی

> کارنکس هم‌بنیان‌گذار هوشمند برای استارتاپ‌های ایرانی است — محصول زنده با پرداخت زیبال، در هفته‌های اول لانچ؛ سرمایهٔ کوچک برای ۶ ماه یادگیری و رسیدن به اولین ۱۰۰ بنیان‌گذار پرداخت‌کننده.

## اسلایدهای ۵‌تایی (برای تماس / PDF کوتاه)

1. **مسئله:** بنیان‌گذار ایرانی بین چت پراکنده، فایل ورد و مشاورهٔ گران گیر می‌کند.
2. **راه‌حل:** کارنکس — بوم، نقشه راه ایران‌محور، پیچ‌دک، کوپایلوت روی یک پروژه.
3. **وضعیت الان (صادقانه):** محصول live؛ ترافیک برند + اینستا/تردز؛ کاربران ارگانیک کم؛ پرداخت واقعی را جدا از تست گزارش کن (اسکوربورد ارگانیک ادمین).
4. **برنامه ۳۰/۶۰/۹۰:** مصاحبه → یک کانال رشد → فیکس فانل → SEO مسئله‌محور (`/guides`).
5. **Ask:** سرمایهٔ پل برای ۶ ماه — زندگی بنیان‌گذار + هزینه AI/هاست + آزمایش رشد سبک. **نه** حقوق تیم ۵ نفره.

## چک‌لیست مواد

- [ ] دمو ویدئو ≤ ۲ دقیقه (محصول واقعی، نه اسلاید خالی)
- [ ] عددهای **ارگانیک** از ادمین (نه ۲۰ کاربر تست)
- [ ] لینک PostHog funnel (اختیاری برای مشاوره‌های عمیق)
- [ ] لیست ۱۰–۲۰ مخاطب + وضعیت پاسخ

## معیار کلوز راند واقعی (بعداً)

- ۵۰+ ثبت‌نام ارگانیک در بازهٔ منسجم
- ≥۳۰٪ به پروژه / فعال‌سازی برسند
- ۵–۱۰ پرداخت واقعی **یا** مصاحبهٔ قوی با تمایل پرداخت
- retention هفته ۴ نزدیک صفر نباشد
- داستان کانال: چطور ۱۰۰ نفر بعدی را بدون فقط سرچ برند می‌آوری
