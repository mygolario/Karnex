# اسکریپت مصاحبه کاربر — کارنکس (۱۵ دقیقه)

هدف: فهمیدن **چرا** آمده‌اند، کجا گیر می‌کنند، و آیا حاضرند برای پرو (~۲۹۹ هزار تومان) پول بدهند.
هر کاربر ارگانیک جدید را همین هفته صدا بزن. تست‌ها را مصاحبه نکن.

## قبل از تماس

1. در ادمین → کاربران → فیلتر **فقط ارگانیک** → جزئیات کاربر را باز کن.
2. مرحله فانل، تعداد پروژه، آخرین فعالیت، پرداخت را یادداشت کن.
3. در PostHog Person / Replay یک نگاه سریع بینداز.

## پیام دعوت (کپی)

```
سلام [نام]، آریو از کارنکس هستم.
دیدم ثبت‌نام کردی — ممنون. اگر ۱۵ دقیقه وقت داری دوست دارم بدونم ایده/مسیرت چی بوده و کجا محصول کمک کرده یا گیج‌کننده بوده.
نه فروش، فقط یادگیری. کدوم روز/ساعت برات راحت‌تره؟
```

## سوالات (به ترتیب)

1. **شغل کارنکس:** قبل از پیدا کردن ما، برای «از ایده تا مسیر» چه می‌کردی؟ (چت‌جی‌پی‌تی، اکسل، مشاور، هیچی…)
2. **ورود:** چطور کارنکس را پیدا کردی؟ (اینستاگرام / گوگل / دوست / …)
3. **لحظهٔ اول:** بعد از ثبت‌نام اولین کاری که کردی چه بود؟ کجا گیر کردی یا خوشحال شدی؟
4. **ارزش:** اگر فقط یک چیز از محصول بماند، کدام است؟ (بوم / نقشه راه / پیچ‌دک / دستیار)
5. **پرداخت:** اگر پرو ماهانه حدود ۲۹۹ هزار تومان باشد، امروز می‌خری؟ اگر نه — چه چیزی باید درست شود یا چه قیمتی منطقی است؟
6. **توصیه:** به یک دوست بنیان‌گذار چطور کارنکس را معرفی می‌کنی؟ (یک جمله)
